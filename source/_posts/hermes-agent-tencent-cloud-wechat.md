[Hermes Agent](https://github.com/NousResearch/hermes-agent) 是 Nous Research 于 2026 年 4 月开源的自主 AI 智能体。它最抓人的一点是**会自我成长**：一边有跨会话的持久记忆，一边能自主创建技能、并在使用中不断改进这些技能——「越用越聪明」这件事，它给了一条能落地的路子。

它和常见聊天机器人的定位也不同。官方强调它**并不依赖你的笔记本电脑**，优先推荐跑在 Linux 环境里。放到云服务器上，你能拿到三样东西：和本地电脑**安全隔离**、**7×24 小时不间断在线**、以及随时用**微信、企业微信、飞书、钉钉**跟它对话。

腾讯云轻量应用服务器（Lighthouse）是跑它最省事的载体：腾讯云市场已经上架了**官方的 Hermes Agent 应用镜像**，买完服务器开机就是一个装好的 Hermes；更关键的是，腾讯云为这个镜像在控制台里做了一个**可视化的 Hermes Agent 配置面板**——配模型、接微信、装技能，全部在网页上点鼠标完成，**一行命令都不用敲**。

本文按小白视角写，主线就是：**注册 → 买服务器选镜像 → 打开配置面板 → 配模型 → 扫码接微信 → 装技能 → 开聊**。

{% note danger %}
**必须提前知道的三件事**（不然装完会失望）：

1. **一个微信只能连一个 Agent**。如果这个微信之前授权过别的 Agent（比如 OpenClaw），再次授权会**解除原来的连接**。
2. **配置面板目前只支持一个默认模型**，后配的会覆盖先配的，想换就重新配一次。
3. **它要花钱**：服务器有月租，模型调用按 token 计费。不是一次买断。
{% endnote %}

> **边界说明**：本文是对开源项目与云服务商公开产品的部署流程整理，仅供学习参考，**不构成对任何产品、服务或费用的承诺**。各家价格、镜像上架情况、平台接口可能随时变化，请以官方页面为准。部署和使用 AI 智能体时，请遵守相关平台的服务条款与所在地法律法规。

## 一、动手前：成本与地域怎么选

**大概要花多少？**

| 项目 | 说明 | 成本 |
|---|---|---|
| 云服务器 | 腾讯云轻量应用服务器，**推荐 2 核 4G**，最低 2 核 2G 仅够简单体验 | 几十元/月，新用户有优惠 |
| 大模型 | 腾讯云通用 Token Plan，或自备 MiniMax / DeepSeek 的 Key | 按用量，轻度使用几元到几十元/月 |
| 微信账号 | 一个能扫码的个人微信 | 免费 |

**地域怎么选？** 国内、海外地域都支持，按你要用的东西来定：

| 看你打算 | 建议 |
|---|---|
| 主要调国内模型 | 国内地域 |
| 主要用微信、企业微信、飞书、钉钉 | 国内地域 |
| 主要用 Discord 这类海外聊天软件 | 海外地域 |

{% note info %}
Hermes Agent **不支持 Windows 原生环境**。Windows 用户想跑在自己电脑上，得先装 WSL2 再在里面运行——这也是推荐直接上云服务器的原因之一。
{% endnote %}

## 三、第二步：把 Hermes Agent 装到服务器上

两条路，选一条就行。

### 方式一：新购一台（推荐）

还没有腾讯云账号？先 [点此注册腾讯云](https://curl.qcloud.com/lxNLjrln)（新用户有专属优惠），完成实名认证后进 [轻量应用服务器购买页](https://console.cloud.tencent.com/lighthouse/instance/index) 下单。

| 选项 | 怎么选 | 说明 |
|---|---|---|
| **应用创建方式** | 选「**使用应用镜像**」，在应用列表里选 **Hermes Agent** | 这就是装好即用的那个镜像 |
| **地域** | 按上一节的对照表选 | 国内用国内地域 |
| **套餐** | **推荐 2 核 4G**；最低 2 核 2G 仅适合简单体验 | 内存大一点跑技能更从容 |
| **登录方式 / 名称** | 按需，没特殊要求可先跳过 | 后面都能改 |

勾选协议后点**立即购买**，跟着页面引导完成支付。服务器创建大约需要 **30 秒**，之后去 [轻量云控制台](https://console.cloud.tencent.com/lighthouse/instance/index) 就能看到它——**此时 Hermes Agent 已经装好了**。

### 方式二：重装一台现有的

{% note danger %}
**重装系统会清空服务器内原有的全部数据**。有重要内容的话，先在备份选项里选「备份后重装」，或手动做一次快照。
{% endnote %}

1. 进 [轻量云控制台](https://console.cloud.tencent.com/lighthouse/instance/index)，找到要重装的那台实例
2. 点实例卡片右上角的 **`...`** → 选**重装系统**
3. 按下表选择：

| 选项 | 怎么选 |
|---|---|
| 镜像 | **使用应用模板 → 龙虾专区 → Hermes Agent** |
| 登录凭证 | **重装后设置** |
| 备份选项 | **备份后重装（推荐）**；确认无需保留才选「直接重装」 |

4. 确认并勾选已了解重装须知 → 点**确定**

稍等片刻重装完成，回到控制台即可。

## 四、第三步：打开 Hermes Agent 配置面板

这是整件事的关键一步，也是腾讯云这个镜像最省事的地方。

1. 进 [轻量云控制台](https://console.cloud.tencent.com/lighthouse/instance/index)
2. 点你装了 Hermes Agent 的那台**实例卡片任意空白处**，进入**实例详情页**
3. 在详情页的**顶部导航**里，点**「应用管理」**页签

进去之后你会看到 **Hermes Agent 配置面板**，从左到右依次是三块区域：

| 区域 | 管什么 |
|---|---|
| **模型（Models）** | 接哪个大模型、设不设为默认 |
| **通道（Channels）** | **接微信就在这里** |
| **技能（Skills）** | 装各种能力扩展 |

{% note info %}
配模型、接微信、装技能，**全部在这个面板里点鼠标完成，不用登录服务器敲命令**。这是腾讯云为 Hermes Agent 应用模板专门做的。
{% endnote %}

{% note warning %}
**如果「应用管理」页里只有「应用内软件信息」**（只有版本号、官方文档和实践教程的链接），没有上面那三栏面板——说明你的镜像版本较旧，还没集成可视化配置面板。

**解决办法**：按第三节方式二**重装系统**，把 Hermes Agent 应用模板升到最新版，就能看到面板了。**重装会清空数据，务必先做快照备份。**
{% endnote %}

## 五、第四步：给它装上「脑子」（配置模型）

Hermes Agent 本身**不含 AI 模型**，得给它接一个外部大模型来驱动。

模型区域有两个下拉框：**上面选模型提供商（Provider），下面选该提供商下的具体模型**，选好后点下方的**「一键添加为默认」**。稍等片刻，下方**「当前模型」**区域显示出你刚配的那条，就代表生效了。

### 最省事：腾讯云通用 Token Plan

**不需要你自己去申请 API Key，直接选中就能用**，想快速体验的首选。

1. Provider 下拉框选 **腾讯云通用 Token Plan**
2. 模型下拉框选一个具体模型
3. 点**一键添加为默认**，此时分两种情况：

| 情况 | 会看到什么 | 怎么做 |
|---|---|---|
| **还没买过 Token Plan** | 弹窗提示「您尚未购买 Token Plan 套餐，请先购买后再使用一键配置」 | 点弹窗里的**前往购买** → 按引导买套餐 → 回面板点**已购买，继续配置** |
| **已经买过** | 直接配置成功 | 看「当前模型」区域即可 |

{% note info %}
如果账号开了操作保护，点按钮后会弹身份验证窗口，**用手机微信扫码**或选其他方式验证一下就能继续。
{% endnote %}

### 用自己的 Key：MiniMax / DeepSeek

如果你已经有 MiniMax、DeepSeek 的账号，更想用自己的 Key，流程也一样：选 Provider → 选模型 → 把 Key 粘进输入框 → 点**一键添加为默认**。

| Provider | 去哪拿 Key | Key 长什么样 |
|---|---|---|
| **MiniMax Token Plan** | [MiniMax 开放平台 - Token Plan 页](https://platform.minimaxi.com/user-center/payment/token-plan)，在 **Token Plan Key** 区域点复制 | `sk-cp-` 开头 |
| **DeepSeek** | [DeepSeek 开放平台 - API Keys 页](https://platform.deepseek.com/api_keys)，点**创建 API Key** 并立即复制保存 | `sk-` 开头 |

{% note danger %}
**API Key 等于一把钥匙，能花你账号里的钱，别外泄给任何人。**

另外三点常见坑：**按量付费的账号余额为 0 时，Key 填对了也调不动模型**；Key 复制时前后带了空格或换行会失效；该 Key 的权限不包含你选的模型也会失败。
{% endnote %}

{% note warning %}
面板**目前只支持添加一个模型**。每次「一键添加为默认」都会**覆盖上一次的配置**。想换模型，重新选一次、再加一次默认即可。
{% endnote %}

## 六、第五步：点「授权接入」，扫码连微信

模型配好，就差一个能跟它说话的入口了。

1. 在配置面板的**通道（Channels）** 区域，通道下拉框**默认已经选中微信**，保持默认
2. 点下方的**「授权接入」**按钮
3. 页面上弹出一个**二维码**，**用手机微信扫一扫**
4. 手机上会弹出授权页，提示「将新的 OpenClaw / Hermes Agent 连接到微信」，点页面底部的**「继续连接」**
5. 回到配置面板，**「已接入通道」区域多了一条微信记录** —— 这就代表接入成功了

{% note danger %}
**一个微信只能连一个 Agent。**

如果你的微信此前已经授权过另一个 Agent（例如 OpenClaw），页面会提示「当前微信已连接一个 OpenClaw，继续连接将解除原有的连接」。**点继续连接会覆盖掉原来的授权**，旧的连接会失效。
{% endnote %}

{% note warning %}
扫码出问题，先查这两条：**二维码是有有效期的**，过期就关掉弹窗、重新点一次「授权接入」拿新码；**确认你扫码用的微信，就是你想收消息的那个微信号**。
{% endnote %}

## 七、第六步：给它装一双「手」（技能）

到这一步，它已经有「脑子」和「对话入口」了。技能（Skills）是让它真正能干活的部分——拓展具体能力。

面板里安装技能的来源是腾讯云的技能平台 [SkillHub](https://www.skillhub.cn)，装法如下（以 `self-improving-agent` 为例，这个技能顾名思义，能让它在被使用的过程中不断自我改进，很配「越用越聪明」这个场景）：

1. 在**技能（Skills）** 区域上方的**搜索输入框**里输入 `self-improving-agent`
2. 在下拉出的候选结果里**选中它**
3. 点下方的**「安装技能」**按钮
4. 弹出安全提示：「部分技能（Skills）由第三方社区收录，可能存在安全风险，安装前请仔细检查」→ 可以点弹窗里的**「点击前往」**去 SkillHub 核对详情 → 确认没问题后点底部的**「确定」**
5. 安装完成后，**「已安装技能」**区域会显示出它

{% note danger %}
**技能安装涉及从 SkillHub 拉取代码并执行，部分技能由第三方社区收录，存在安全风险。装之前先去 SkillHub 看清楚说明和评价，别装来路不明的技能。**
{% endnote %}

{% note info %}
想找更多技能：点技能区域的**「前往 SkillHub」**，在 [SkillHub](https://www.skillhub.cn) 里按类别或关键词浏览，**记下技能的准确名称**，再回到面板的搜索框里安装。
{% endnote %}

## 八、第七步：在微信里开聊

全都配完之后，打开手机微信，找到刚才授权接入的 Hermes Agent 对应的**微信联系人**，直接发一条消息试试：

```
你好，请做一下自我介绍
```

一切正常的话，它会用你配好的模型生成一段回复，出现在微信聊天窗口里。

{% note info %}
后面想**换模型、换通道、加技能**，随时回到实例详情页的**「应用管理」**页改：模型直接覆盖添加；通道和技能在「已接入 / 已安装」列表里，按提示移除后重新配置即可。
{% endnote %}

## 九、常见问题

| 问题 | 怎么办 |
|---|---|
| **能同时配多个模型吗** | 目前只支持一个默认模型。想换就重新选 Provider 和模型、再点一次「一键添加为默认」，新的覆盖旧的 |
| **粘了 Key 点添加没反应** | ① Key 前后带了空格或换行，重新复制粘贴；② 账号余额为 0，先去开放平台充值；③ 该 Key 的权限不含所选模型，去开放平台确认 |
| **微信扫码提示授权失败** | 确认扫码的微信就是你要收消息的那个号；二维码过期就关掉弹窗，重新点「授权接入」 |
| **技能搜不到** | 先点「前往 SkillHub」确认技能的**准确名称**和是否已上架，再回来搜 |
| **应用管理页没有三栏面板** | 镜像版本旧，按第三节方式二重装升级（**先做快照备份**） |
| **想换模型 / 通道 / 技能** | 回「应用管理」页对应区域，模型覆盖添加，通道和技能在列表里移除后重配 |

## 十、成本与安全

**成本**：每月固定支出是**服务器月租 + 模型 token 费用**。省钱的做法：先用新用户优惠跑一个月，确认真能用得上再续；Token Plan 套餐按实际用量买，别一上来冲顶配；定期看一眼账单，防止某个失控的任务悄悄烧钱。

**安全**上记住三条：

| 风险点 | 怎么做 |
|---|---|
| **API Key** | 等同于花钱的钥匙，不外泄、不提交到公开仓库，定期轮换 |
| **技能来源** | 只装 SkillHub 上说明清楚、评价正常的技能，不装来路不明的 |
| **微信连接** | 记住一个微信只能连一个 Agent，重复授权会解绑旧的 |

## 小结

整条链路其实很短，而且**全程不用敲一行命令**：**注册腾讯云 → 买轻量服务器选 Hermes Agent 镜像 → 控制台「应用管理」打开配置面板 → 配模型 → 点「授权接入」扫码连微信 → 装技能 → 开聊**。

真正需要花心思的不是安装，而是想清楚**「让它帮你干什么」**——定时简报、资料归档、信息监控、项目提醒，这些才是它比普通聊天机器人值钱的地方。

{% note info %}
**顺带一提**：如果你之前玩过 OpenClaw（龙虾），Hermes Agent 内置了 `hermes claw migrate` 命令，支持把 OpenClaw 的设置、记忆、技能和 API 密钥一键迁移过来，不用从头配置。
{% endnote %}
