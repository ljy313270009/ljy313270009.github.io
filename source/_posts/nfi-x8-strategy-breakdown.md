前面六篇写的都是「一套指标讲一个故事」的策略：均线加 OBV 讲突破，布林加 RSI 讲回归，逻辑自洽、一页纸能说清。这篇拆一个完全相反的物种——[NostalgiaForInfinity](https://github.com/iterativv/NostalgiaForInfinity)（圈内叫 NFI）的 X8：Freqtrade 社区星星最多、维护最久的免费开源策略，单个文件六万多行代码，维护到 v18 代。

它值得一拆的原因恰恰是「不好读」：没人能逐行读完它。但把结构抽出来看，它的设计思路非常清楚——**不做一套万能逻辑，而是把市场切成很多种状态，每种状态配一组专属规则**。理解了这个骨架，六万行就不再可怕。

{% note info %}
本文只描述策略的代码逻辑与设计取舍，不含任何回测收益率、胜率、盈亏比、交易笔数、样本区间等数据。文中版本为撰写时仓库主线版本，该策略迭代频繁，细节可能随版本变化。
{% endnote %}

## 一、基本盘

| 项 | 设定 | 说明 |
|---|---|---|
| 主周期 | 5 分钟 | 官方明确锁定，不允许在 config 里覆盖 |
| 参考周期 | 15 分钟 / 1 小时 / 4 小时 / 1 天 | 多周期 informative，高周期定方向，低周期找入场点 |
| BTC 参考 | 4 小时 | 所有币种额外参考 BTC 走势，作为整体市场环境的过滤 |
| 方向 | 双向 | 同时持有多、空两套体系；现货模式只跑多头 |
| 杠杆 | 按模式组区分 | 合约模式下，常规单、补仓单、磨单各自配不同杠杆 |
| 启动数据 | 800 根 K 线 | 需要足够的历史才能算齐多周期指标 |
| 信号处理 | 每根新 K 线只算一次 | 5m 高频下的标准省资源配置 |

多周期是它的第一个骨架：5 分钟定执行，1 天和 4 小时定环境，中间的 15 分钟、1 小时做衔接。再加上一条「全市场都看 BTC 脸色」的公共信息源，等于给每个币的每次决策都叠了一层大盘背景。

## 二、指标池

它用的指标都是最常见的那一批，没有秘密武器：

| 指标 | 在这里的角色 |
|---|---|
| EMA / SMA 多组 | 短中长期趋势与乖离判断 |
| 布林带 | 超买超卖与波动区间 |
| RSI / 快速随机指标 | 摆动极端度，快速随机对 5m 反应更快 |
| MFI（资金流量指数） | 带成交量的 RSI，判断资金进出 |
| OBV / CMF（ Chaikin 资金流 ） | 量价配合，识别吸筹与派发 |
| ROC / KST | 动量与综合动量 |
| Williams %R / Aroon | 超卖极值与趋势启动检测 |
| 滚动最高最低 / 标准差 | 区间位置与波动特征 |

单个指标平平无奇，重点在组合方式——同一批指标在不同周期上重复计算，再按模式组的需要拼装成几十上百条规则。

## 三、入场：模式组路由

这是整个策略的灵魂。它没有一条「入场逻辑」，而是把入场规则按**模式组（mode tags）**分类，每条规则触发时打上自己的标签。多头五十多个标签、空头四十多个标签，分成九类模式：

| 模式组 | 定位 |
|---|---|
| normal（常规） | 普通行情下的主力规则，数量最多 |
| pump（暴涨） | 针对「正在暴涨的币」的顺势规则 |
| quick（快速） | 抓快速回落后的反弹 |
| rebuy（补仓） | 已持仓时触发加仓的规则 |
| high profit（高盈利） | 只在浮盈显著时入场的顺势单 |
| rapid（急速） | 极端急跌后的极速反应 |
| grind（磨） | 越跌越买的摊低成本体系，后面细说 |
| top coins（主流币） | 只对头部币种生效的规则 |
| scalp（剥头皮） | 超短打一枪就走的规则 |

理解成一张路由表：行情落在哪种状态，就由哪个模式组接管。暴涨的币、阴跌的币、主流币、山寨币，遇到的是完全不同的规则集。**这就是为什么它必须打 entry tag**——不只是为了统计，更是因为出场、杠杆、仓位调整全都按这个 tag 路由。

## 四、出场：与入场镜像成对

出场结构和入场严格对称：每个模式组都有自己对应的出场函数——常规单用常规出场，磨单用磨单出场，剥头皮单用剥头皮出场。入场时打了什么标签，出场时就走哪套规则。

两个值得注意的设计：

- **不用固定 ROI 止盈表**。传统策略常见「涨 2% 就走」的阶梯 ROI，它没有。利润目标是在运行中动态标记和计算的：入场后按规则标记目标价，达到即出，不同模式组的目标逻辑不同。
- **出场规则比入场还厚**。除了各模式组的常规出场，还有专门的 Williams %R 出场、十二月出场（年底特殊行情处理）等独立函数。高风险策略的生存之道从来不在进得多准，而在出得多讲究。

## 五、风险控制：不用止损，用体系

这是它最反直觉的地方：**静态止损设成 -99%，等于不设**；自定义止损也关闭。真正的风险控制由三层体系替代：

1. **降风险阶梯（de-risk ladder）**：浮亏进入不同深度时，触发分级降风险出场，一级、二级、三级递进，像楼道里的应急灯逐层亮起。
2. **坏单控制器（bad trade controller）**：专门识别「接飞刀」的单子——入场后 EMA 乖离拉大且价格持续逆向走、或以特定坏方式出场的单，会被单独标记并特殊处理，包括强制离场和「投降式」清仓分支。
3. **仓位调整体系**：`position_adjustment` 全开，包含三套动作——
   - **rebuy（补仓）**：浮亏到设定深度加仓摊成本；
   - **grind（磨）**：比补仓更激进的越跌越买，专吃深跌后的回弹；
   - **buyback（买回）**：卖出后行情延续时重新接回。

也就是说，它的风控哲学是「**跌了不认赔，而是分批接、阶梯降、控制总敞口**」。这套打法在震荡市如鱼得水，代价是遇到单边不回头的行情会持续接飞刀——所以才需要坏单控制器来当最后一道闸。

## 六、设计要点与取舍

把它和前面六篇「单逻辑策略」放在一起，对比非常鲜明：

| | 单逻辑策略（前六篇风格） | X8 规则库 |
|---|---|---|
| 核心思路 | 一套指标讲一个故事 | 市场状态机，按模式路由 |
| 可读性 | 一页纸 | 六万行，只能看骨架 |
| 出场 | 一条主规则 + 兜底 | 与入场成对的专属规则集 |
| 亏损处理 | 止损离场 | 补仓、磨单、阶梯降风险 |
| 有效性来源 | 逻辑本身 | 社区多年实盘反馈 + 高频迭代 |
| 适配周期 | 中低频 | 5 分钟高频，7×24 不间断 |

它把「过拟合怎么办」这个问题给了一个很特别的答案：**不追求一套规则永久有效，而是持续修**。市场变了就改规则、加模式组，版本号一路演进到 v18。这解释了它为什么免费开源却常年活跃——规则库的价值在迭代速度，藏起来就没意义了。

{% note warning %}
想直接拿来跑的话要有心理预期：官方要求 5 分钟周期、建议较多并发仓位和较宽的币池、config 关键项不许覆盖；且它迭代很快，实盘得跟着仓库更新。更重要的是，「越跌越买」的仓位体系对资金管理要求高，黑盒程度也高——出了问题很难定位是哪条规则干的。当对照基准和设计参考的价值，大概率大于直接抄去实盘。
{% endnote %}

运行前置：这类 5 分钟级策略对连续性敏感，回测本地电脑即可，实盘需要一台 7×24 长期在线的机器。
